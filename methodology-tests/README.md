# Methodology tests

These folders follow the Chapter 3 (v5) labels.

- **design-experiments/** holds DE-1 to DE-5. These compare component options during development.
- **acceptance-tests/** holds ATP-1 to ATP-9. These evaluate the completed system with separate, held-back cases.

The .gitkeep files preserve each otherwise empty folder in Git. Replace each marker as its protocol, data and code are added. Keep development cases out of the final acceptance sets.
